Agent 任務看板

每張卡片是一個 /ship-issue 任務，位置來自 change 目錄裡 handoff.md 的「## 狀態」區塊，完成度來自 tasks.md 的勾選。

示範資料：以下任務皆為虛構，用來展示各種狀態

資料來源與目前的限制

  • 只讀 wt/<change-id>/openspec/changes/<change-id>/handoff.md 的狀態區塊與同目錄的 tasks.md；歸檔後改讀 openspec/changes/archive/<日期>-<change-id>/。
  • 「PR 中檢查」無法再分成 CI、/code-review、/security-review，細節請看「最後完成」與「下一步」。
  • 歸檔（archived）後一律顯示「合併隊列」，分不出合併中、已合併或合併失敗；合併失敗時流程不改階段，卡片會停在這裡。
  • 「等待審批」只有高風險任務會經過，虛線格代表這一步可能被略過。
  • 階段值不在對照表中，或找不到狀態區塊時，顯示「無法辨識」並附上原始值，不猜測位置。
