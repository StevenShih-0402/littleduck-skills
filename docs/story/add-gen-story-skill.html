實際操作

怎麼跑一份導覽

  1. 產生：在專案根目錄執行 /gen-story <change-id>docs/story/<change-id>.html 出現一份單檔投影片
  2. 開啟：瀏覽器打開該 HTML，用 ← → 或空白鍵翻頁對話帶你看決策，程式碼標了路徑與行號
  3. 版面檢查：PLAYWRIGHT_FROM=<playwright-repo-root> \ node .claude/skills/gen-story/scripts/check_layout.mjs \ docs/story/<change-id>.html --shots out/shotsN 頁版面檢查通過（exit 0）
